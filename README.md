# FX Launcher

A dark, minimal Android home launcher prototype for the FX product ecosystem.

## Features
- Can be selected as the Android home app
- Live clock and date
- FX product quick-launch cards
- Installed app drawer
- Android home settings and about dialog

## Build
GitHub Actions builds a debug APK on every push to `main`. Open Actions and download the `FX-Launcher-APK` artifact from a successful run.

This is an early prototype. FX product cards launch matching installed apps when found; they do not bundle those apps.
